# Digital Forensics Case Study: Arson Investigation

## Project Overview

This project presents an academic digital forensics case study completed
as part of CJ310 Digital Forensic Analysis at ECPI University.

The examination involved reviewing a supplied forensic disk image and
documenting digital artifacts relevant to a simulated arson investigation.

The project emphasizes forensic artifact analysis, evidence documentation,
email examination, deleted-file identification, and investigative reporting.

## Investigation Objectives

- Examine available digital artifacts from a forensic disk image.
- Document recovered images and email communications.
- Identify deleted and encrypted files reported by the forensic tool.
- Organize findings into an investigative timeline where supported.
- Document limitations and distinguish findings from assumptions.

## Tools and Technologies

- Magnet AXIOM
- Digital forensic disk-image analysis
- Email artifact examination
- File metadata analysis
- Digital evidence documentation

## Key Findings

The supplied examination report documented:

- Three recovered fire-related image records.
- Email artifacts associated with the investigation.
- An encrypted ZIP file identified by the forensic software.
- A deleted Word document recovered through artifact parsing.
- Information relevant to further investigative analysis.

These findings are based on the supplied examination report.
The underlying contents of the encrypted archive and deleted document
were not established in the report.

## Methodology

The project documents the examination objectives, evidence reviewed,
reported artifact findings, and investigative conclusions.

The report also identifies examination procedures involving evidence
integrity, forensic imaging, cryptographic hashing, and artifact analysis.

Planned procedures should not be interpreted as completed procedures
unless the report documents their completion.

## Limitations

The project is based on an academic case study and the supplied
examination report.

The presence of an artifact does not independently establish who created
it, who controlled an associated account, or whether a person committed
a crime.

The underlying forensic image is not included in this repository.
